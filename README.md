# Food Delivery Delay Analysis and Prediction

## Project Overview
This project explores a real-world food delivery dataset to understand the factors associated with delivery duration and predict the time taken to deliver an order.

## Objectives
- Perform data cleaning and exploratory data analysis.
- Analyze numerical and categorical variables using visualizations.
- Engineer useful features, including order time and geographical distance.
- Train and evaluate regression models for delivery-time prediction.

## Dataset
The original dataset contains 45,593 records and 20 fields.

**Dataset source:** [https://www.kaggle.com/datasets/gauravmalik26/food-delivery-dataset?select=train.csv]

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- TensorFlow / Keras
- Google Colab / Jupyter Notebook

## Models
- Mean-prediction baseline
- Random Forest Regressor
- Multilayer Perceptron (MLP) neural network

## Results
The selected Random Forest model achieved the following results on the test set in the recorded run:

- MAE: approximately 3.16 minutes
- RMSE: approximately 4.00 minutes
- R²: approximately 0.8140

## Project Files
- Jupyter Notebook: data cleaning, EDA, visualization, preprocessing and modeling.
- Project Report: methodology, findings, model evaluation and conclusion.

## How to Run
1. Download or open the notebook in Google Colab.
2. Obtain the dataset from the source linked above.
3. Update the dataset path if needed.
4. Run the notebook cells in order.
